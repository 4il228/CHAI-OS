<h1 align="center">CHAI OS</h1>
<h3 align="center">Операционная система с искусственным интеллектом на базе NixOS</h3>

<p align="center">
  <i>Говорите системе что делать — она сделает. Никакого Bash. Никакого ручного администрирования.</i>
</p>

---

## Философия

**CHAI OS** — полноценная операционная система на базе NixOS, спроектированная для bare-metal. Ключевая парадигма — полный отказ от ручного системного администрирования в пользу естественно-языкового промпт-интерфейса.

Пользователь описывает желаемое состояние системы на естественном языке, а резидентный ИИ-сервис:

1. Генерирует декларативные Nix-выражения
2. Разрешает зависимости и собирает систему
3. Активирует новые профили атомарно и без риска повреждения ОС

## Архитектура

```
[Запрос на естественном языке]
         │
         ▼
  ┌─────────────────┐
  │   chai-shell    │  ИИ-шелл (REPL, Catppuccin Mocha)
  │  (Rust REPL)    │
  └────────┬────────┘
           │ JSON-RPC 2.0
           ▼
  ┌─────────────────┐
  │    chai-core    │  Управляющий демон (статический Rust)
  │  (Rust Daemon)  │
  └──┬──────────┬───┘
     │          │
     ▼          ▼
  ┌──────┐  ┌──────┐
  │ LLM  │  │ Nix  │  Генерация и валидация
  │Client│  │Gen   │  Nix-выражений
  └──────┘  └──┬───┘
               │ nix-instantiate --parse
               ▼
        ┌──────────────┐
        │  /etc/nixos/  │  Атомарное применение
        │  config.nix   │
        └──────┬───────┘
               │ nixos-rebuild switch
               ▼
        ┌──────────────┐
        │   New Gen    │  Откат через загрузчик
        │  (Immutable) │
        └──────────────┘
```

### Компоненты

| Компонент | Язык | Назначение |
| :--- | :--- | :--- |
| **chai-core** | Rust | Фоновый демон: JSON-RPC 2.0 сервер, LLM-клиент, синтезатор Nix |
| **chai-shell** | Rust | REPL-интерфейс: естественный язык + POSIX-префикс `!` |
| **eBPF LSM** | C/eBPF | Фильтрация системных вызовов на уровне Ring 0 |
| **Nix Flakes** | Nix | Декларативная конфигурация всей системы |

## Конвейер исполнения

```
Запрос в chai-shell / TTY
        │
        ▼
  Парсинг намерений (LLM)
        │
        ▼
  Генерация декларативного Nix-кода
        │
        ▼
  Анализ рисков безопасности (eBPF Core)
        │
        ▼
  Вывод diff конфигурации (Human-in-the-Loop)
        │
        ▼
  Одобрение оператором
        │
        ▼
  Сборка новой деривации Nix (новое поколение)
        │
        ▼
  Атомарная активация профиля (nixos-rebuild switch)
```

## Возможности

- **Естественно-языковое администрирование** — никакого знания Nix-синтаксиса или флагов пакетного менеджера
- **Два режима шелла** — ИИ-промпт (по умолчанию) и POSIX-команды через префикс `!`
- **Двойной инференс** — локальный Ollama (оффлайн, Qwen-2.5-Coder) или облачные API (OpenAI, Anthropic, Gemini) с BYOK
- **Атомарные обновления** — каждое изменение создаёт поколение в загрузчике с гарантированным откатом
- **Graceful Degradation** — при недоступности LLM шелл переходит в диагностический POSIX-режим
- **Безопасность Ring 0** — eBPF LSM изолирует пути файловой системы от ИИ-агента
- **Установка через ИИ** — ISO-образ с ИИ-парсером дисковой разметки

## Быстрый старт

> Система в активной разработке. Инструкция по установке появится после завершения фазы Bootstrap.

```bash
# Загрузиться с ISO
# Ввести в chai-shell:
Установи систему на весь диск NVMe, зашифруй LUKS,
создай пользователя chai_user и настрой Hyprland

# ИИ-агент выполнит разметку, сгенерирует конфиги и запустит nixos-install
```
